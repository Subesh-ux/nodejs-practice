# Text Tools

A simple text utility package.

## Installation

npm install @subesh07/text-tools

## Usage

import { capitalize, reverse, countWords, removeSpaces, isPalindrome } from "@subesh07/text-tools";

console.log(capitalize("hello"));
console.log(reverse("hello"));
console.log(countWords("Hello World"));
console.log(removeSpaces("Hello World"));
console.log(isPalindrome("madam"));
